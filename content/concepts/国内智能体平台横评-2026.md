# 国内智能体平台横评 2026

> **一句话**：2026 年是国内 Agent 平台"从概念到落地"的关键之年。40+ 款龙虾工具混战，实测能商用的不到 10 款，**大厂"生态整合派"（腾讯 WorkBuddy）赢过"单点突破派"（DeepSeek）**。

---

## 🎯 6 大行业共识（跨 12 篇一手 source 综合）

### 共识 1：Agent 竞争 = 生态整合竞争
来源：[[sources/128-CSDN-40款龙虾工具横评]] + [[sources/137-53AI-一文吃透WorkBuddy]]
- 40 款龙虾里能真正商用不到 10 款
- 大部分是"套壳 OpenClaw + 单点能力"
- **生态完整（MCP + Skill + Agent + 专家团）> 单点突破**

### 共识 2："龙虾"（Claw）已是行业黑话
来源：[[sources/128-CSDN-40款龙虾工具横评]] + [[sources/130-新浪财经-三只国产龙虾比较]]
- 特指 OpenClaw 类"通用桌面 Agent"
- 腾讯 QClaw / 字节 ArkClaw / 阿里 CoPaw 都在跟进
- **"龙虾"已经具备产品品类的意涵**

### 共识 3：2026 是"智能体大规模应用的关键之年"
来源：[[sources/136-36kr-五款办公Agent实测]]
- 头部办公 Agent 月访问量合计超 2000 万次
- 中国 AI 大模型日均 Token 调用量突破 140 万亿（连续 5 周超美国）
- **市场准备好了，产品还没准备好**

### 共识 4：三大路线分化
来源：[[sources/130-新浪财经-三只国产龙虾比较]]
- **腾讯"人味"路线**：微信 + 混元 + 消费级 UX
- **字节"极客"路线**：能力上限 + 技术流
- **阿里"开源"路线**：ModelScope + 社区共创
- 三条路线代表 Agent 三种可能未来

### 共识 5：办公场景已成主战场
来源：[[sources/136-36kr-五款办公Agent实测]] + [[sources/137-53AI-一文吃透WorkBuddy]]
- 5 款办公 Agent 综合排名：**WorkBuddy > DuMate > 悟空 > 豆包 > 清言 Agent**
- 关键能力：搭应用 / 接钉钉 / Skill 库 / MCP 生态
- **办公 Agent 就是 2026 版 Office**

### 共识 6：微信集成是护城河
来源：[[sources/133-36kr-腾讯QClaw体验]] + [[sources/137-53AI-一文吃透WorkBuddy]]
- 只有腾讯能把 Agent 塞进微信
- **微信 + Agent = 别人复制不了的组合**
- QClaw 战略核心：让 AI 在你的微信生态里干活

## 🌍 大厂战略地图

来源：[[sources/127-搜狐-国产AI六巨头逐鹿Agent]] + [[sources/128-CSDN-40款龙虾工具横评]]

```
         生态优势 强
           │
   腾讯 ⭐  │
  (WorkBuddy+QClaw+混元) │
           │
─────阿里───┼───百度────
(QwenPaw+CoPaw)│(DuMate+千帆)
           │
   字节 ⭐  │  DeepSeek ❌
 (Coze+ArkClaw)│(模型强Agent弱)
           │
           │  月之暗面 ❌
           │ (Kimi Work下线)
           │
         生态优势 弱
```

**四个象限判断**：
- **腾讯**：生态最全 + 战略最坚定 → 可能领跑
- **字节**：消费级强 + 企业级弱 → 抖音/飞书主战场
- **阿里/百度**：全家桶策略 + 商用积累 → 稳中求进
- **DeepSeek/月之暗面**：模型强 + Agent 弱 → 变成给别人当基座

## 🚨 5 大反共识

来源：[[sources/131-36kr-养虾人为什么卸载龙虾]] + [[sources/132-阿里CoPaw上手体验]] + [[sources/134-Manus深度评测]]

### 反共识 1：龙虾热潮 = 泡沫 + 方向正确
- 一月火爆，四月大规模卸载
- OpenClaw 微信搜索热度已跌至高峰期的 **3%**
- **方向对，产品不成熟**：等成本降 10x + 稳定性上一档 + 部署零门槛

### 反共识 2：模型好 ≠ Agent 强
- DeepSeek / 通义模型排名前，Agent 落后
- 腾讯 WorkBuddy 靠"混元 + MCP + Skill + 微信"整合胜出
- **Agent 是系统工程，不是模型工程**

### 反共识 3：Token 定价掏空钱包
- 陈汉每天 3 条天气 + 早报，一个月烧 $500
- **按 Token 计费对高频用户是敲诈**
- 未来需要包月无限 + 缓存优化

### 反共识 4：开源 ≠ 稳定
- 阿里 CoPaw 官方开源，但消息中断、进度虚报、记忆丢失
- **开源解决的是"生态"，不是"稳定性"**

### 反共识 5：合规风险 > 技术风险
- Manus 全球首款通用 Agent，GAIA SOTA，被 Meta 20 亿收购，被发改委叫停
- **AI 出海：合规 > 技术**

## 🔮 3 大趋势预判

### 趋势 1：办公 Agent 就是 2026 版 Office
- 5 款办公 Agent 月访问量 2000 万+
- WorkBuddy 已排第一（885 万）
- **传统 Office 加 AI Copilot 追不上 Agent 原生产品**

### 趋势 2：微信 Agent 是腾讯独家护城河
- QClaw 微信集成 = 别人复制不了的组合
- **"AI 在微信里帮你干活"是 To C Agent 最强 PMF**

### 趋势 3：Super Agent 平台是新品类
- Genspark：50+ 模型 + 多 Agent 协同
- Manus：多模型协同 + GAIA SOTA
- **不是聊天机器人，是 AI 工作空间**
