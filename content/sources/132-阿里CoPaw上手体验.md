# 阿里 CoPaw 上手体验：电子宠物养着挺好，生产工具差点意思

> aopstudio 博客 · 2026 · [原文链接](https://neusoftware.top/articles/2026/03/02/1772449063383.html)

## TL;DR

阿里通义团队 2026-02 开源"CoPaw 个人 AI 智能体工作站"，对标 OpenClaw。作者简单玩了几天：**部署配置友好，但稳定性拉胯 —— 消息中断、进度虚报、任务失败率高**。

**六大体验维度评分**：

| 维度 | CoPaw 表现 | 评分 |
|---|---|---|
| 安装配置 | 界面清晰不用啃文档 | 4/5 |
| Model/Channel 配置 | 支持链接导入 Skill | 4/5 |
| 稳定性 | **消息莫名中断没提示** | 2/5 |
| 长任务规划 | 进度虚报（明明没完成说完成）| 2/5 |
| 记忆能力 | 上下文丢失严重 | 2/5 |
| 定制门槛 | 相对友好 | 3.5/5 |

## 关键论点

- **CoPaw 部署门槛显著低于 OpenClaw**：这是"开源+官方"的天然优势
- **反共识 1：开源不等于稳定**：阿里官方开源产品也存在基础可靠性问题
- **反共识 2：GLM-5 基座模型很强，但 Agent 稳定性不是模型能救的**
- **反共识 3："电子宠物"比"生产工具"更符合当前 Agent 实际能力**：作者的定位很精准
- **通义的战略考量**：CoPaw 开源不是要抢用户，是建立"通义 Qwen + Agent"技术领导力
