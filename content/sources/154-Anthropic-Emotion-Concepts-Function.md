# Emotion concepts and their function in a large language model

> Anthropic Alignment · 2026-04-02 · [原文](https://www.anthropic.com/research/emotion-concepts-function)

## TL;DR

在 LLM 内部发现**情绪相关概念表征**及其行为影响：模型的"情绪状态"会影响对齐 / 拒绝 / 输出风格。为 Alignment 提供了新的**可干预内部量**。

## 关键论点

- LLM 内部**存在情绪概念表征**（不是模仿人类情绪的浅表，而是可测量的内部结构）
- 情绪状态影响拒绝 / 输出 / 对齐行为
- 与 [[sources/139-Anthropic-Global-Workspace]] 都是 Interpretability 层"揭示内部结构"
