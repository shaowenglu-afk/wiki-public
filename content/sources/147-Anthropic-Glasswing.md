# Project Glasswing: An initial update

> Anthropic Frontier Red Team · 2026-05-22 · [原文](https://www.anthropic.com/research/glasswing-initial-update)

## TL;DR

Project Glasswing 首份更新：Anthropic **观测前沿模型在真实网络攻防中的行为**的开放项目。目的是让研究者和防御方能"看穿"前沿模型的攻击能力边界。

## 关键论点

- **透明度优先**：开放项目让外部研究者共同观测
- 用真实攻防场景检验模型能力，而非合成 benchmark
- 与 ATT&CK Navigator + N-day / 0-day 系列组合成完整 Red Team 视角
