# 4 款国产通用智能体深度横评：百度 DuMate、WorkBuddy、QoderWork、QClaw 六大维度实测

> 苏米客 · 2026 · [原文链接](https://www.xmsumi.com/detail/3273)

## TL;DR

用同一份任务实测 4 款头部通用智能体（Computer Use 型 Agent），六大维度评分：**WorkBuddy 综合第一，DuMate 商用最稳，QoderWork 编程最强，QClaw 微信集成独特**。

**六大维度对比**：

| 维度 | 百度 DuMate | 腾讯 WorkBuddy | QoderWork | 腾讯 QClaw |
|---|---|---|---|---|
| 桌面/浏览器操控 | 中 | **强** | 中 | 弱 |
| 表格 / Excel | 强 | 强 | 中 | 中 |
| PPT / 幻灯片 | 中 | **强** | 中 | 中 |
| 代码 / 编程 | 弱 | 中 | **强** | 弱 |
| 长链任务规划 | 中 | 强 | 中 | 中 |
| 微信 / 沟通集成 | 无 | 无 | 无 | **强** |
| **综合** | 3.5/5 | **4.5/5** | 4/5 | 3.5/5 |

## 关键论点

- **通用智能体 = 长了手脚的 AI**：不是聊天，是"直接操作电脑/浏览器/应用程序"完成跨平台任务
- **WorkBuddy 靠"专家团 + Skill 生态"胜出**：不是单点能力强，是整体解决方案完整
- **QoderWork 编程强但通用弱**：适合开发者，不适合一般办公用户
- **QClaw 微信生态是独门武器**：其他 Agent 都做不到"AI 帮你在微信里干活"
- **DuMate 稳但没惊喜**：适合金融保守用户
- **反共识**：不要迷信"能操作电脑"的噱头，**能真正跨应用交付才是核心价值**
