# 五款 Agent 办公实测：悟空接钉钉，DuMate 搭应用，WorkBuddy 敢"拒单"，豆包呢？

> 36kr · 2026-07-04 · [原文链接](https://36kr.com/p/3868529576655491)

## TL;DR

2026 年 3 月，桌面端办公 Agent 迎来爆发。**头部产品月访问量合计超 2000 万次，腾讯 WorkBuddy 以 885 万排第一**。行业数据：中国 AI 大模型日均 Token 调用量突破 140 万亿，连续 5 周超越美国。

**5 款办公 Agent 实测评分**：

| 产品 | 厂商 | 亮点 | 短板 | 综合 |
|---|---|---|---|---|
| **WorkBuddy** | 腾讯 | "敢拒单"（不会不懂装懂）| 生态刚起步 | 4.5/5 |
| **DuMate** | 百度 | 搭应用能力强 | 稳定性一般 | 4/5 |
| **悟空** | 阿里 | 接钉钉最深 | 独立场景弱 | 4/5 |
| **豆包** | 字节 | 消费级 UX 好 | 企业能力弱 | 3.5/5 |
| **智谱清言 Agent** | 智谱 | 模型强 | Agent 组合弱 | 3/5 |

**用户不满原因**（易观分析）：
1. 需求理解偏差 46%
2. 产出质量不及预期 42%
3. 响应慢 (次要)
4. 大文件处理受限 (次要)
5. 执行中断 (次要)

## 关键论点

- **WorkBuddy 敢拒单是最大差异化**：不会不懂装懂，说"这个我做不了"比"胡说八道"重要 100 倍
- **办公 Agent 的护城河 = 生态集成**：悟空接钉钉、DuMate 搭应用，谁能"最少让用户切换 App"谁赢
- **反共识 1：Agent 执行力已经不是核心瓶颈**：46% 用户不满是"理解偏差"，54% 是"产出质量"，都不是执行力问题
- **反共识 2：中国 Token 调用量已超美国**：不是没有需求，是产品体验不匹配
- **反共识 3："智能体大规模应用的关键之年" = 2026**：行业共识
