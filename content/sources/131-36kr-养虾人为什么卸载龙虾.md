# "养虾人"自述：我为什么卸载龙虾？

> 36kr · 2026-07-04 · [原文链接](https://36kr.com/p/3801338129915398)

## TL;DR

OpenClaw 一月火爆全网，四月大规模卸载。**微信搜索热度已跌至高峰期的 3%**。作者采访六位"养虾人"（含大厂员工、券商分析师），还原从积极入局到愤然离场的转变。

**六位养虾人卸载原因排行**：

| 原因 | 用户占比 | 具体案例 |
|---|---|---|
| **Token 消耗掏空钱包** | 5/6 | 陈汉每天推送 3 条天气 + 早报，一个月烧 $500 |
| **稳定性差（记忆缺失/进度虚报）** | 4/6 | 张女士事务所法务任务被 Agent 反复"报告完成"但实际未完成 |
| **部署门槛高 + 找人安装花钱** | 3/6 | 花上千装配没搞定 |
| **安全漏洞（本地数据被删）** | 2/6 | 王工程师 3 个月工作数据被永久删除 |
| **竞品更好（Hermes 等）** | 3/6 | 换到 Hermes 后不再回头 |

## 关键论点

- **龙虾热潮 = 泡沫 + 方向正确**：受访者都承认方向是对的，但产品还没到普通人能用的水平
- **反共识 1：本地部署 ≠ 更安全**：本地 Agent 有权限调用系统资源，反而更危险
- **反共识 2：Token 定价模型不可持续**：按 Token 计费的定价对高频用户是敲诈
- **反共识 3：AI Agent 的"数字员工"承诺目前是伪命题**：稳定性、成本、部署三大门槛都没跨过
- **等待条件**：成本降 10x + 稳定性上一个台阶 + 部署零门槛，Agent 才算真正到普通人能用的一天
