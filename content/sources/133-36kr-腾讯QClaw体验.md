# 腾讯「龙虾」QClaw 体验：AI 能连微信干活了，但整体还很粗糙

> 36kr · 2026-07-04 · [原文链接](https://www.36kr.com/p/3728581722092039)

## TL;DR

2026 年 3 月 18 日，腾讯把 QClaw 以邀请制方式放了出来。作者深度体验后总结：**QClaw 最大的亮点是"接入微信"，能真正在你的微信生态里干活，但整体产品还很粗糙**。

**QClaw 三大差异化**：
1. **微信原生集成** — 唯一能操作微信的通用 Agent
2. **开箱即用** — 不用配 Docker、Python、部署脚本
3. **本地运行更安全** — 敏感数据不上云

**三大槽点**：
1. 稳定性一般（复杂任务经常失败）
2. Skill 生态还在起步阶段
3. 微信集成场景边界模糊（合规不明确）

## 关键论点

- **QClaw 的战略定位不是"和 OpenClaw 竞争"**：而是"让普通用户能用上 Agent"
- **微信集成是护城河**：其他厂商很难跨这道墙
- **反共识 1：套壳 OpenClaw 不是问题，产品化才是**：腾讯做的是"把 OpenClaw 变成普通人能用的产品"
- **反共识 2：本地运行更符合国内合规**：数据不上云 = 通过金融/政府/央企采购
- **反共识 3：微信这个渠道 =《微信生态里的 AI 助手》**：不需要下载新 App，直接对话就能干活
- **粗糙但方向对**：作者判断"3-6 个月迭代后可能成为 To C Agent 第一"
