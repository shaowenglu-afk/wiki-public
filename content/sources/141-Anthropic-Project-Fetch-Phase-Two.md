# Project Fetch: Phase two

> Anthropic · 2026-06-18 · [原文](https://www.anthropic.com/research/project-fetch-phase-two)

## TL;DR

Project Fetch 二期：让 Claude 训练**四足机器狗**执行复杂任务。二期扩展到更长任务链路、更真实场景，验证 **LLM 作为具身智能 Agent 大脑** 的可行性。

## 关键论点

- 从"Claude 训练机器狗"进化到 **多阶段任务 + 真实环境**
- **Embodied AI + Agentic Planning** 的一次一手实验
- 与"Long-running Claude"共享工程范式
