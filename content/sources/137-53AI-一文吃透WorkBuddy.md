# 一文吃透腾讯 WorkBuddy 全功能：模式、模型、技能、连接器、专家与自动化实操指南

> 53AI · 2026-07-02 · [原文链接](https://www.53ai.com/news/shuziyuangong/2026070251790.html)

## TL;DR

腾讯 WorkBuddy 六大核心板块完整拆解：**工作模式（Ask/Plan/Craft）+ 模型选择 + 技能（Skill）+ 连接器（MCP）+ 专家（Agent）+ 自动化**。作者判断"整合了 MCP、Skill、Agent、Agentic System，基本配备到完美"。

**六大模块速查**：

| 模块 | 含义 | 例子 |
|---|---|---|
| **工作模式** | Ask / Plan / Craft 三种 | Ask 聊天 → Plan 规划 → Craft 执行 |
| **模型** | 支持混元 Hy3 preview / 智谱 / MiniMax / DeepSeek / KIMI | 可自定义 API Key 接入 |
| **技能（Skill）** | 官方 + 社区 Skill 库 | 高考志愿填报助手 / Excel 处理 / 杂志风 PPT |
| **连接器（MCP）** | Model Context Protocol 中文命名 | 高德地图 / 元典法律数据 |
| **专家（Agent）** | 封装一系列流程的智能体 | 内容创作专家 / 投研分析专家 |
| **专家团** | 多智能体协作系统 | 内容创作专家团（选题→大纲→创作）|

## 关键论点

- **WorkBuddy = 完整 Agentic System**：MCP + Skill + Agent + 专家团整合到位
- **反共识 1："连接器" 比 "MCP" 好用**：腾讯把 MCP 翻译成"连接器"，普通用户秒懂
- **反共识 2：Skill 生态是核心，模型不是**：好的 Skill 可以让 WorkBuddy 秒变行业专家
- **反共识 3：专家团是多 Agent 落地的标准形态**：不是"编排"，是"一队专家协作"的直观隐喻
- **腾讯生态优势**：混元 + 混元 Skill + 微信 + 混元 PPT/Doc 一整套配好，不用用户到各处找
