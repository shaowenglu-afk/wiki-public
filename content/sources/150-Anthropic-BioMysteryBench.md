# Evaluating Claude for Bioinformatics with BioMysteryBench

> Anthropic Science · 2026-04-29 · [原文](https://www.anthropic.com/research/Evaluating-Claude-For-Bioinformatics-With-BioMysteryBench)

## TL;DR

推出 **BioMysteryBench**：用真实生物信息学"谜题"衡量 Claude 的科学推理能力。给 Agentic Science 提供**领域专属基准**，不再依赖通用 benchmark。

## 关键论点

- 领域基准比通用基准更能反映 Agent 的**真实科学能力**
- 与 [[sources/143-Anthropic-Agents-in-Biology]] 相配套
- 为其他领域（Chemistry / Physics）建立同类基准提供样板
