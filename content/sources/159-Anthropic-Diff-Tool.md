# A "diff" tool for AI: Finding behavioral differences in new models

> Anthropic · 2026-03-13 · [原文](https://www.anthropic.com/research/diff-tool)

## TL;DR

发布 **AI 版 diff 工具**：不比对代码，比对**模型行为差异**。用来在训练迭代 / 版本升级时快速找出"新模型跟旧模型哪里不一样"。

## 关键论点

- **行为 diff** 是模型演进的关键观测手段
- 不是"benchmark 分数变了"，是"具体哪些输出模式变了"
- 与 [[concepts/AI-可观测性-四维追踪]] 呼应，是 Model-level 可观测性

## 与本 wiki 关联

- 组合：[[concepts/AI-可观测性-四维追踪]]

## 一句话总结

> **模型迭代的关键观测手段 = 行为 diff。分数变了不够，得看具体哪些输出变了。**
