# 腾讯 WorkBuddy、字节 ArkClaw、阿里 CoPaw：三只国产"龙虾"的比较和启发

> 新浪财经 · 2026-03-23 · [原文链接](https://finance.sina.com.cn/roll/2026-03-23/doc-inhrxevz5647020.shtml)

## TL;DR

三大互联网巨头几乎同时推出对标 OpenClaw 的通用 Agent：**腾讯 WorkBuddy / 字节 ArkClaw / 阿里 CoPaw**。三家路线各异：**腾讯做"人味"、字节做"极客"、阿里做"开源"**。

**路线定位**：

| 厂商 | 产品 | 核心策略 | 目标用户 |
|---|---|---|---|
| **腾讯** | WorkBuddy | "人味"路线：微信生态 + 消费级体验 | 中小企业 + 白领 |
| **字节** | ArkClaw | "极客"路线：能力上限最高 + 技术流 | 开发者 + 深度用户 |
| **阿里** | CoPaw | "开源"路线：ModelScope 开源版 + 社区自建 | 极客 + 学生 |

## 关键论点

- **三家路线判断的启发**：不是"谁 Agent 更强"，而是"谁更懂自己的用户"
- **腾讯的"人味"是护城河**：微信 + 混元 + 完整生态 + 消费级 UX 组合起来别人复制不了
- **字节的"极客"是双刃剑**：能力天花板高但门槛也高，普通用户望而却步
- **阿里的"开源"是长期主义**：短期没有商业化压力，长期建立技术领导力
- **反共识**：**Agent 竞争不是模型竞争，是"如何让 AI 真的能干活"的产品和生态竞争**
- 三家分别对应了通用 Agent 的三种可能未来：**消费级 / 极客级 / 开源自主**
