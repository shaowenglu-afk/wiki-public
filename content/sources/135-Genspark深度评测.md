# Genspark 深度评测：从搜索到执行，这个全能工作空间到底有多能打

> AI 星球 · 2026 · [原文链接](https://www.aixq.cc/34877.html)

## TL;DR

Genspark 由 MainFunc 公司打造，创始团队来自前百度小度核心管理层（CEO 景鲲 + CTO 朱凯华）。2024-06 以 AI 搜索引擎起步，2025 年底转型为 **Super Agent 平台**，红杉领投 2 亿美元融资，估值突破 10 亿。

**核心能力（$25/月）**：

| 能力 | Genspark 表现 |
|---|---|
| **50+ 模型集成** | GPT-5.2 / Claude Opus 4.5 / Gemini 3 Pro |
| 搜索 → 结构化页面（Sparkpages）| 强项 |
| 电话外呼预约 | 独特能力 |
| 报告生成 | 强 |
| 幻灯片制作 | 中 |
| 视频生成 | 中 |
| 代码编写 | 中 |
| 多代理协同 | Super Agent 核心 |

## 关键论点

- **Genspark ≠ 聊天机器人，是"AI 工作空间"**：竞品不是 ChatGPT，是"一个能顶半个助理"的产品
- **多代理协同架构**：不同任务调用不同模型 / 不同 Agent 组合
- **反共识 1：搜索引擎转型 Super Agent 有先天优势**：搜索基础设施 = Agent 的信息底盘
- **反共识 2：50+ 模型不是噱头**：不同任务需要不同模型的最佳能力
- **反共识 3：电话外呼是"最不 AI"的能力**：但恰恰是"Agent 真的能干活"的最强证据
- **产品定位比 Manus 更清晰**：明确说"我不是聊天机器人，是工作空间"
