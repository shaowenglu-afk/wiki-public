# AutoGen

> **一句话**：**微软开源多 Agent 框架**，主打"角色扮演式"多 Agent 对话（UserProxy · Assistant · GroupChat）。是 2024-2025 学术界最活跃的多 Agent 实验平台，2026 生产环境逐步被 [[entities/LangGraph]] 和 [[entities/Microsoft-AGT]] 分流。

## 核心特征

- **对话式协作**：Agent 之间用自然语言对话，UserProxy 承担人的角色
- **Group Chat 模式**：多 Agent 群聊 + 一个 Moderator 决策
- **代码执行**：Assistant Agent 可直接执行 Python
- **和 [[entities/CrewAI]] 的差异**：AutoGen 更偏"研究友好"，CrewAI 更偏"业务角色 friendly"
- **微软阵营演进**：AutoGen → Microsoft AGT（企业向）
