# WorkBuddy · 腾讯

> 腾讯 2026 年推出的**企业 / 白领办公 Agent**，头部办公 Agent 月访问量 **885 万排第一**。

## 一句话档案

**WorkBuddy = 完整 Agentic System**：整合 MCP（连接器）+ Skill（技能）+ Agent（专家）+ 专家团（多智能体协作）+ 混元模型 + 微信生态。

## 六大核心模块

1. **工作模式**：Ask（聊天）/ Plan（规划）/ Craft（执行）三档递进
2. **模型**：混元 Hy3 preview + 智谱 + MiniMax + DeepSeek + KIMI 多选
3. **技能（Skill）**：官方 + 社区 Skill 库（Excel、PPT、投研等）
4. **连接器（MCP）**：MCP 中文命名，含高德地图、元典法律等
5. **专家（Agent）**：封装流程的智能体（内容创作 / 投研分析）
6. **专家团**：多智能体协作系统（选题→大纲→创作）

## 核心差异化

- **"敢拒单"**：不会不懂装懂，说"这个我做不了"比"胡说八道"重要
- **生态整合最全**：MCP + Skill + Agent 一站配齐
- **中文原生**：把 MCP 翻译成"连接器"、把 Agent 翻译成"专家"

## 竞争定位

- 综合排名：办公 Agent 第一（885 万月访问）
- 对标：Coze / Dify / DuMate / Copilot Studio
- 战略：与 QClaw 组成腾讯双 Agent 战略（企业+个人）
