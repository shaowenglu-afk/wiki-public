# ArkClaw · 字节龙虾

> 字节跳动 2026 年推出的通用 Agent，**极客路线代表**：能力上限最高、技术流深度用户友好。

## 一句话档案

**ArkClaw = 字节"极客路线"通用 Agent**：技术上限高、深度用户友好、消费级 UX 不是重点。

## 战略定位

- 与 Coze 组成字节双 Agent 战略：**Coze 消费级 + ArkClaw 极客级**
- 字节生态：抖音、飞书、剪映
- 路线：技术天花板 > 用户友好

## 核心能力

- **能力上限高**：多模态、多任务、多 Agent 编排
- **技术流深度定制**：适合工程团队和深度用户
- **Coze 的高级形态**：与 Coze 形成"消费→极客"梯度

## 短板

- 门槛高，普通用户难上手
- 消费级 UX 不如 Coze 流畅

## 竞争定位

- 对标：OpenClaw / QClaw / CoPaw
- 差异化：能力天花板最高
- 战略：为技术流用户准备的 Agent 天花板
