# CrewAI

> **一句话**：**"业务角色式"多 Agent 框架** —— 让开发者用"Role + Goal + Backstory"三要素定义 Agent，用"Crew"组队执行任务。2024-2026 最快融资的开源多 Agent 项目，业务侧 friendly 使得金融/营销团队能直接用。

## 核心特征

- **Role-based 建模**：Agent = Role（角色）+ Goal（目标）+ Backstory（背景）
- **Crew 组队**：Sequential / Hierarchical 两种执行模式
- **业务友好**：非技术 PM 也能定义 Crew，触及 [[concepts/低代码-vs-高代码-智能体建设]]
- **和 [[entities/AutoGen]] 的差异**：CrewAI = 业务角色抽象，AutoGen = 对话式研究抽象
- **和 [[entities/LangGraph]] 的差异**：CrewAI = high-level 声明，LangGraph = low-level 图编排
