# QClaw · 腾讯龙虾

> 腾讯于 2026-03-18 邀请制推出的通用 Agent。**核心差异化：接入微信，可以在你的微信生态里干活**。

## 一句话档案

**QClaw = OpenClaw 的腾讯产品化版**：开箱即用 + 微信原生集成 + 本地运行更安全。

## 核心能力

- **微信原生集成**：唯一能操作微信的通用 Agent
- **开箱即用**：不用 Docker/Python 部署脚本
- **本地运行**：敏感数据不上云，合规友好
- **邀请制**：目前只开放小范围测试

## 竞争定位

- 对标：OpenClaw / ArkClaw / CoPaw
- 差异化：微信生态整合（其他厂商复制不了）
- 短板：Skill 生态起步阶段 + 复杂任务稳定性一般
