# Genspark · MainFunc

> MainFunc（前百度小度核心团队 CEO 景鲲 + CTO 朱凯华）打造的 **Super Agent 平台**。2025 年从"AI 搜索引擎"转型为多代理协同工作空间。

## 一句话档案

**Genspark = AI 工作空间新品类**：50+ 模型集成 + 多代理协同 + 电话外呼 + 报告 / 幻灯片 / 视频一体化。

## 关键数据

- 上线：2024-06 Beta（AI 搜索起步）
- 融资：2025 红杉领投 2 亿美元，估值 10 亿+
- 战略转型：2025 年底 → Super Agent 平台
- 定价：$25/月

## 核心能力

- **50+ 模型集成**：GPT-5.2 / Claude Opus 4.5 / Gemini 3 Pro 等
- **Sparkpages**：多代理生成结构化搜索页面
- **电话外呼**：独特能力，可预约、查询、催单
- **多能力整合**：搜索 / 图片 / 视频 / 幻灯片 / 数据分析 / 代码
- **多代理协同**：Super Agent 核心架构

## 差异化

- **产品定位比 Manus 更清晰**："我不是聊天机器人，是工作空间"
- **搜索引擎转型 Super Agent 有先天优势**：信息底盘完整
- **多模型协同 = 不同任务用不同模型的最佳能力**

## 竞争定位

- 对标：Manus / OpenAI Deep Research / ChatGPT
- 差异化：电话外呼是"最不 AI"但"最接地气"的能力
- 战略：一个人顶半个助理的 AI 工作台
