# Tyk

> **一句话**：英国开源 **API 管理平台**，2026 发布 **AI Agent Orchestration** 白皮书，把自己定位为**企业级 Agent 治理层** —— 4 大架构组件 + [[entities/A2A-Protocol]] 支持 + 3 种治理模式。

## 核心特征

- **4 大组件**：Agent Registry · Policy Engine · Runtime Router · Observability
- **A2A Protocol**：跨 Agent 通信标准（[[entities/A2A-Protocol]]）
- **3 种治理模式**：Centralized（大型集团）/ Federated（子公司）/ Marketplace（多租户）
- **和 [[entities/Kong]] / [[entities/Higress]] 的差异**：Tyk 强调 **agent-to-agent orchestration**，不只是 model routing
