# Petri · Anthropic 开源对齐审计工具

## 一句话档案

**Petri = Anthropic 内部对齐审计工具**，2026-05-07 开源捐赠。让整个 AI 安全生态可以用同一套工具做审计，加速对齐研究。

- **对齐审计** 自动化框架
- 覆盖：agentic 行为 / 输出偏差 / persona 切换 / 越狱等
- 与 Anthropic 内部 Alignment 团队工作一致

## 战略意义

- **从"公司内部工具"到"社区共用工具"**
- 让研究者 / 防御方共用同一评估基础设施
