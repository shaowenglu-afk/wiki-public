# DuMate · 百度红手指

> 百度 2026 年推出的通用 Agent，**擅长搭应用、商用积累深、金融保守用户友好**。

## 一句话档案

**DuMate = 百度商用 Agent 稳中求进代表**：搭应用能力强 + 商用积累深 + ERNIE 生态。

## 核心能力

- **搭应用能力最强**：能快速生成企业内部应用
- **商用积累深**：继承百度千帆商用积累
- **ERNIE 模型底盘**：文心大模型深度绑定
- **金融保守用户友好**：稳定性优先于新奇能力

## 短板

- 稳定性一般（非商用场景）
- Agent 编排 UX 不如 Coze / WorkBuddy
- Skill 生态起步阶段

## 竞争定位

- 综合评分：办公 Agent 第二档
- 对标：WorkBuddy / QoderWork / QClaw
- 战略：To B 商用友好路线（对标 Salesforce Agentforce）
