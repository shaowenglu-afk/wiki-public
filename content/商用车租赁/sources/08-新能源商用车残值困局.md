# 新能源商用车残值困局："买家不认"

> 卡车之家行业调查 + 网易/时代周报补充 · [原文](https://www.360che.com/news/250506/196797.html)

## TL;DR

这是整个新能源商用车租赁最硬的一堵墙。**残值率 42.9% vs 燃油车 60%+**，而且不是价格问题而是**定价能力问题**——85% 的二手车商没有检测设备，93% 的大型企业员工看不懂 BMS 数据。租赁公司做经营性租赁要吃残值风险，但这个市场目前根本给不出可信的残值曲线。

## 关键论点 / 数据

**残值率差距**

| 类型 | 残值率 |
|---|---|
| 新能源商用车 | **42.9%** |
| 传统燃油商用车 | **60% 以上** |

- 一辆 **50 万元**的新能源重卡，残值不到 **25 万元**；同等燃油车达 **30 万元**
- 某二手交易案例：新能源车平均成交 **30 万元**，同期燃油车 **60–90 万元**，价差超 **100%**
- 另一组数据：2023 年上牌、新车购置价约 **70 万元**的电动重卡，行驶 **30 多万公里**后残值仅约 **20 万元**，且难以出手

**评估能力的缺失（更致命）**
- **85%** 的二手车商缺乏专业检测设备
- **93%** 的大型企业员工不了解 BMS 系统数据
- 电池残值与同品牌燃油车的电池评估相差 **5–8 万元**
- 燃油商用车有成熟的"**车龄 + 里程**"折旧模型；新能源车残值受**电池健康度、品牌存续性**等多因素影响，**定价随意性强**

**电池衰减的物理原因**
营运车辆长期满负荷连续运转，高低温循环、频繁大功率充放电造成**不可逆锂损耗持续累积**。买家对衰减极度敏感——"一听说电池只剩七成电量就会放弃购买"。

**恶性循环**
缺乏统一检测标准 → 权威评估体系不健全 → 信息不对称 → 买家认知缺陷 → 市场流通性差 → 更没人愿意建标准。

## 对租赁业务的直接后果

1. **经营性租赁在新能源商用车上几乎做不了**——残值算不出来，出租人无法定价风险
2. **融资租赁的处置回收假设要打折**——违约拖车后，车卖不掉等于回收率归零
3. **反过来说，这也是机会**：谁先建立起可信的新能源商用车残值模型和处置渠道，谁就拿到了这个市场的定价权（对照 [[商用车租赁/sources/03-狮桥商业模式拆解]] 里狮桥在燃油车时代建车型库 + 机器学习估值模型的路径）

> 新能源商用车残值率只有 42.9%，但真正的问题不是低，而是没人算得准——这让出租人无法承担残值风险，经营性租赁在这个品类上暂时是个伪命题。
